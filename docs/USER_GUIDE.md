# 智能刷题（Android 版）使用说明

> 面向普通用户：**不需要写代码、不需要配置环境**，下载安装包即可使用。
> 想基于本仓库二次开发，请看 [README](../README.md) 与 [INTERFACES.md](INTERFACES.md)。

---

## 一、系统要求

| 项目 | 要求 |
| --- | --- |
| 系统版本 | Android 8.0（API 26）及以上 |
| 设备 | 安卓手机 / 安卓平板 |
| 不支持 | iPhone、iPad（iOS 无安装包） |
| 鸿蒙设备 | 需支持安装安卓 APK（部分机型需先在设置里关闭「纯净模式」） |
| 存储空间 | 建议预留 100 MB 以上 |
| 网络 | 基础刷题可完全离线；AI 功能需联网；局域网联机需接入同一 WiFi |

## 三、安装

### 3.1 把安装包传到手机

任选一种：数据线拷贝、微信/QQ 发送到「文件传输助手」、网盘下载、浏览器直接下载。

### 3.2 允许安装未知来源应用

安装时系统会提示「禁止安装未知应用」：

1. 点击提示框中的「设置」；
2. 找到「允许安装未知应用 / 安装未知来源应用」并打开；
3. 返回后重新点击 APK 安装。

### 3.3 常见安装提示的处理

| 提示 | 原因与处理 |
| --- | --- |
| 已阻止安装，可能存在风险 | 系统安全检测的正常提示。确认文件来自本仓库后，选择「仍然安装 / 继续安装」 |
| 解析软件包时出现问题 | 安装包下载不完整或系统版本过低。重新下载并用上表大小、SHA-256 校验；确认系统为 Android 8.0 以上 |
| 应用未安装 / 签名冲突 | 手机上已有同包名的旧版本且签名不同。先卸载旧版再安装（**卸载会清除本地数据，请先导出题库**） |
| 鸿蒙提示「应用来源未知」 | 设置 → 系统和更新 → 纯净模式 → 关闭后重试 |
| 提示存储空间不足 | 清理空间后重试 |

> 升级安装（覆盖安装）不会清除数据；只有卸载才会删除本地题库与记录。

## 四、第一次打开

1. 点击桌面图标启动，进入启动页后自动进入首页。
2. 底部导航为五个入口：**首页（题库）/ 刷题 / 错题 / 统计 / 我的（设置）**。
3. 建议先在「设置」里完成两件事：
   - 填写自己的大模型 API 密钥（可选，用于 AI 判卷、AI 解析）；
   - 了解数据仅保存在本机，必要时定期导出题库备份。

---

## 五、题库管理

### 5.1 新建题库

首页 →「新建题库」→ 输入名称 → 保存。一个 App 里可以建多个题库，按考试科目分开管理。

### 5.2 导入题目

进入题库 →「导入 / 上传」：

- 支持文件：**PDF、Word（docx）、Excel、TXT**；
- 系统会先切分题目并预览，确认无误后再写入题库；
- 若文件格式不规范导致切分异常，可开启「AI 辅助识别」让模型自动整理成题目（需要配置 API 密钥）；
- 导入完成后，题库会统计各题型的题目数量。

### 5.3 手动录题与编辑

题库详情页可以新增、编辑、删除单道题目，支持五种题型：

| 题型 | 说明 |
| --- | --- |
| 单选题 | 一个正确选项 |
| 多选题 | 多个正确选项，需全部选对 |
| 判断题 | 对 / 错 |
| 填空题 | 按空逐一判定，可设置多个空 |
| 简答题 | 主观题，按得分点评分 |

### 5.4 回收站

删除的题目会进入回收站，可随时恢复；确认不再需要时再彻底删除。

## 六、刷题

进入题库后选择刷题模式：

| 模式 | 适用场景 |
| --- | --- |
| 顺序模式 | 按题号稳定推进，适合系统学习 |
| 随机模式 | 题目乱序，避免靠位置记忆 |
| 魔鬼随机 | 题目与选项一起打乱，真正检验掌握程度 |
| 专项模式 | 只刷某一种题型（如只刷多选） |
| 背题模式 | 直接展示答案与解析，考前速记 |

使用要点：

- 答题进度会自动保存，退出后可选择「继续上次」或「重新开始」；
- 支持答题卡，快速跳转到任意一题；
- 提交后立即显示对错与解析；题目没有解析时可让 AI 生成讲解。

### 主观题是怎么判分的

- 配置了 API 密钥：AI 对照标准答案按得分点评分（10 分制，6 分及以上判为通过），并给出命中点、缺失点与评语；
- 未配置密钥或断网：自动使用本地关键词判定，功能不中断；联网后可重新发起 AI 评判。

---

## 七、错题本与收藏

- 答错的题目（含 AI 判为不及格的主观题）自动进入错题本；
- 错题会记录重做次数，达到设定次数后可自动移出；
- 好题可一键收藏，随时二刷；
- 错题与收藏都可以直接发起专项练习。

---

## 八、模拟考试

1. 选择题库 → 配置试卷：题型数量、总分、考试时长、题目顺序、选项是否乱序；
2. 开始考试后进入倒计时答题，支持答题卡；
3. 考试期间切屏次数会被记录，超过上限会自动强制交卷（用于模拟真实考场纪律）；
4. 交卷后：客观题立即判分，主观题按设置由 AI 或人工批阅；
5. 成绩页包含总分、客观题分、主观题分、正确率、用时、未答题数、题型分布；
6. 历史考试记录可回顾整张试卷，逐题查看作答与得分。

---

## 九、局域网联机考试

同一 WiFi 下无需服务器即可组织一场考试：

1. 一人作为「发卷人」创建房间（选择题库与试卷配置）；
2. 其他人在「联机」页输入房间信息加入；
3. 所有人答同一套卷，答题期间可见倒计时；
4. 结束后生成实时排行榜，支持两种批阅方式：
   - 考生自批；
   - 发卷人统一批阅。

**连不上时依次检查：**

- 所有人是否连着**同一个** WiFi（手机热点也可以，但热点的「AP 隔离」需关闭）；
- 路由器是否开启了「AP 隔离 / 访客网络隔离」；
- 手机是否开启了 VPN 或防火墙类应用；
- 人数较多时，请让发卷人保持屏幕常亮。

> 联机功能不依赖互联网，也不经过任何服务器。

## 十、班级与好友（需要服务端）

以下功能属于联网增强模块，需要自行部署服务端（见 [DEPLOY.md](DEPLOY.md)）后才能使用：

- 创建 / 加入班级，成员管理，班级共享题库；
- 班级统一发卷、成绩统计、排行榜、考试监控；
- 好友码加好友、题库直发、收件箱领取。

不部署服务端时，这些入口不可用，但不影响本地刷题、考试与局域网联机。

## 十一、AI 功能配置（可选）

1. 打开「设置」→「AI 配置」；
2. 填入自己的大模型 API 密钥（支持 DeepSeek、火山方舟等 OpenAI 兼容接口）；
3. 保存后可使用的能力：
   - 主观题 AI 判卷；
   - 题目 AI 解析；
   - 考试结束后的 AI 成绩评价（优势 / 不足 / 改进建议）；
   - 题库文件 AI 辅助识别。

**说明：** 密钥由你自己在模型平台申请，费用由平台按用量收取，App 不收取这部分费用；密钥仅保存在本机。

---

## 十二、数据与备份

- 所有题库、答题记录、考试记录都保存在手机本地数据库；
- **卸载 App 或清除应用数据会删除全部本地数据**，操作前请先导出题库；
- 换手机时：旧机导出题库文件 → 新机「导入题库」即可；
- 建议定期导出一次，尤其是题量较大的题库。

## 十四、常见问题（FAQ）

**Q1：安装包打不开 / 提示文件损坏？**
重新下载，核对文件大小为 22.57 MB，并用 SHA-256 校验；确认系统为 Android 8.0 及以上。

**Q2：导入 PDF 后题目乱七八糟？**
不同 PDF 的排版差异很大。建议先用规范的 Word/Excel 模板导入；或开启 AI 辅助识别，让模型整理；也可以导入后手动修正少量题目。

**Q3：哪些题型能自动判分？**
单选、多选、判断、填空可以完全本地判分；简答题需要 AI 密钥，或由人工（发卷人）批阅。

**Q4：没网还能用吗？**
可以。题库、刷题、模拟考试、错题本、局域网联机都是本地能力；只有 AI 与班级/好友功能需要网络。

**Q5：为什么 AI 功能提示失败？**
依次检查：密钥是否填写正确、模型账户是否有余额、手机是否能正常访问模型接口；部分网络环境需要代理。

**Q6：局域网联机搜不到房间？**
确认同一 WiFi、关闭路由器 AP 隔离与访客网络、关闭手机 VPN；必要时让发卷人重新创建房间。

**Q7：换手机数据会丢吗？**
会。数据只在本地，请先导出题库再换机。

**Q8：能同时在多台设备用吗？**
可以，但每台设备的数据相互独立；需要多端同步请部署服务端并使用班级/共享题库功能。
