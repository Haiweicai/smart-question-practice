《智能刷题》第三方 SDK 说明
更新日期：2026年7月6日
根据工信部关于个人信息保护的相关要求，本应用现对所使用的第三方 SDK 进行如下披露。本应用使用的所有第三方 SDK 均为本地功能库，不涉及网络数据上报，不会将您的个人信息传输至任何服务器。
一、SDK 清单
1. AndroidX AppCompat
    用途：提供向后兼容的 Android 组件支持
    提供方：Google
    是否收集个人信息：否
    数据处理：无
2. Material Components for Android
    用途：提供 Material Design 风格的界面组件
    提供方：Google
    版本：1.11.0
    是否收集个人信息：否
    数据处理：无
3. AndroidX Room
    用途：本地 SQLite 数据库 ORM，用于存储题库、答题记录等数据
    提供方：Google
    版本：2.6.1
    是否收集个人信息：否（仅本地数据库操作）
    数据处理：所有数据存储于设备本地，不上传任何服务器
4. AndroidX Navigation
    用途：应用内页面导航管理
    提供方：Google
    版本：2.7.7
    是否收集个人信息：否
    数据处理：无
5. AndroidX Lifecycle
    用途：MVVM 架构支持，管理 UI 与数据的生命周期
    提供方：Google
    版本：2.8.2
    是否收集个人信息：否
    数据处理：无
6. AndroidX RecyclerView
    用途：高效列表展示
    提供方：Google
    版本：1.3.2
    是否收集个人信息：否
    数据处理：无
7. AndroidX ViewPager2
    用途：页面滑动切换
    提供方：Google
    版本：1.1.0
    是否收集个人信息：否
    数据处理：无
8. Gson
    用途：JSON 数据解析与序列化，用于数据导入导出
    提供方：Google
    版本：2.10.1
    是否收集个人信息：否（仅本地数据格式转换）
    数据处理：无网络通信
9. Retrofit
    用途：访问业务服务端与 AI 服务的 HTTP 客户端
    提供方：Square
    版本：2.9.0
    是否收集个人信息：否（仅按业务需要发送请求）
    数据处理：请求由本应用的实现代码发起，内容取决于您的实现
10. OkHttp
    用途：Retrofit 底层网络库
    提供方：Square
    版本：4.12.0
    是否收集个人信息：否
    数据处理：同上
说明：本骨架默认未包含文档解析（如 Apache POI、PDFBox）与图表（MPAndroidChart）依赖。
    如您在二次开发中加入这些库，请同步更新本清单。
二、数据安全说明
1. 本应用所有 SDK 均为开源或公开的本地功能库，不包含任何广告、统计、推送等可能收集个人信息的 SDK。
2. 本应用不集成任何第三方登录、支付、地图、即时通讯等需要联网的 SDK；网络能力仅用于访问您所部署的业务服务端与 AI 服务。
3. 本应用不包含任何埋点、崩溃统计（如 Bugly、Firebase Analytics）等数据上报 SDK。
4. 您可自行审查本应用的依赖列表，详见应用的 build.gradle 文件。
